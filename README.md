# 🚀 İş Yapmama Mazeret Üreteci

**Dünyanın en ciddi ve en gereksiz projesi.**

Bu repository, insanlığın en eski sorununa çözüm getiriyor: "Neden iş yapmıyorum?"

## Özellikler

- Gerçekten çalışır (denedim, mazeretim "test ediyorum" oldu)
- Sonsuz mazeret üretir (aslında 10 tane ama hissettirdiği sonsuz)
- Türkçe, çünkü mazeretler anadilde daha etkili
- Abartılı derecede ciddi bir README'ye sahip

## Kurulum

```bash
git clone https://github.com/Tentivory/is-yapmama-mazeret-ureteci.git
cd is-yapmama-mazeret-ureteci
python3 mazeret.py
```

## Kullanım

Sadece çalıştır. Mazeretini al. İşe gitme. Mutlu ol.
